Mac Sensors for Stream Deck

Mac Sensors shows temperatures, fan speeds, power, CPU usage, memory, storage and network rates on Stream Deck keys and dials, read through read-only macOS interfaces.

Get started → Installation and requirements →

Needs macOS 13.5 or later, the Stream Deck app 7.1 or later with the Node 24 runtime it supplies, and Tahoma Bold, which ships with macOS. No separate sensor app. These are declared floors; Hardware compatibility lists what has actually run.

Version 1.0.1.0 is published as a GitHub release, and its downloads require repository access. Mac Sensors is not on the Elgato Marketplace yet, so there is no public download link.

What goes on the deck

  • Sensor Reading →

    One to four readings on a key. A single reading can have a sparkline, bar or ring under it. A press cycles current, min, max and average. Themes, warning and critical colors.

    Where it goes: A display key on a deck with keys (Stream Deck models); physical key checks are pending

  • Sensor Dial →

    One reading, two rows or three rows on the touch strip. Turn through a reading set; local session min, max and average.

    Where it goes: A dial on a Stream Deck + or + XL

  • Sensor details →

    A Press choice on Sensor Reading: a page of tiles for the reading’s group or your own list, with a Back tile

    Where it goes: Decks with a bundled detail view (Sensor details support)

  • Sensor Control →

    Steers Sensor Dials: next or previous reading, pause, pin, reset statistics

    Where it goes: Any key, pedal or Multi Action step

Which readings appear depends on the Mac and its macOS version. The measured M5 Pro reports 52: 14 from system counters and 38 from the SMC (Readings measured on the M5 Pro). CPU and GPU clock speeds and GPU usage are not offered.

What it does not do

Mac Sensors reads. It has no fan control and cannot write a sensor register. It installs no privileged helper, daemon or kernel extension and needs no administrator password. It makes no internet requests and sends no telemetry. You choose when to copy and share a support report. Privacy has the details.

Mac Sensors 1.0.1.0

1.0.0.0 was the first release. 1.0.1.0 ships the same native readers, byte for byte. The changelog lists every change.

What changed in 1.0.1

Change What you see What you need to do
Key statistics A Sensor Reading key shows MIN, MAX and AVG instead of N/A, on a press or with Value shown on Minimum, Maximum or Average. Mac Sensors keeps them from its reads since the plugin last started reading sensors. Detail tiles show the same numbers. They start over after a gap in that reading. Sensor Dials keep their own session statistics as before. Nothing. A key already set to a statistic shows numbers from its next read.
Page changes keep reading Changing pages, opening sensor details or pressing Back keeps reading going: key MIN, MAX and AVG, sparklines, CPU usage and the rates carry on, and keys do not show Reading sensors. Reading stops 2 seconds after the last Sensor Reading key, Sensor Dial or detail tile leaves the deck. See When reading starts and stops. Nothing.
One redraw per read A key or dial that shows both system and SMC readings changes once per read instead of twice in quick succession, when both sources answer within 100 ms of each other. Nothing.
Read every help The setting under Advanced, Connection explains that one shared read updates every reading key and dial, that changing it clears sparkline history, and that shorter intervals use more processor time. Nothing.
Read every limits A blank value means the 1 second default. A stored value above 5 seconds runs as 5 seconds, so readings no longer expire between reads. Nothing. Pick another interval from the list if you want one.
Counter readings sooner CPU usage and transfer rates appear about a quarter second after reading starts, instead of one full read interval later. Reading starts when the first key, dial or detail tile appears, or a page returns after none was shown for 2 seconds. Nothing.
No old values as live When every reading lapses or fails before the first SMC read completes, keys and dials show Reading sensors instead of keeping old values as live. Nothing.
Missing saved reading A key whose saved reading this Mac does not report says Sensor missing and pick again. Pick another reading under Reading, or wait until this Mac reports it again.
Intel support reports When macOS has no translation flag, as on an Intel Mac, the support report’s translation field now says native instead of unknown. Physical Intel validation is in progress. Nothing.
Panel wording Status text in the settings panel no longer names the plugin as the source of sensor data. The Text font line uses the same spacing as other fields. Nothing.
Processor time PERF.md compares an earlier 1.0.1 candidate, built before key statistics and the 2 second hold, with a rebuild of 1.0.0, each run as a development copy in the Stream Deck app 7.5.0 on the M5 Pro with 32 single-reading keys. The candidate used 0.668% of one core at 1 second against 0.855% for 1.0.0, and 2.478% against 3.164% at 250 ms. The published 1.0.1.0 used 0.704% at 1 second over a 24-hour observation. Performance and resource use has the limits. Nothing.
